# Read Nursery School Website

Responsive school website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, colors and responsive styling
- `script.js` — mobile navigation and current year
- `assets/children-painting.jpg` — image supplied for the project

## Publish on GitHub Pages
Upload the files and the `assets` folder to the repository root. Open **Settings → Pages**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then click **Save**.

## Before public use
The supplied photo visibly contains Alamy watermarks. Publish it only if you have the rights/permission to use it; otherwise replace `assets/children-painting.jpg` with a properly licensed school photo. The location is currently listed as Rwanda; update it to the school's actual address if needed.
