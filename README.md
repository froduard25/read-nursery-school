# Read Nursery School Website

A responsive school website project built with HTML, CSS, and JavaScript for a class assignment.

## Files
- `index.html` — website content and page structure
- `style.css` — responsive design, colors, layout, and animations
- `script.js` — mobile navigation, reveal animations, and demo enquiry form

## Preview on your computer
1. Download and extract the ZIP.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a browser.
4. Internet access is needed to load the sample photos and Google Fonts.

## Publish for free with GitHub Pages
1. Sign in to GitHub.
2. Create a new **public** repository named `read-nursery-school`.
3. Choose to create the repository without a README if you want; either way is fine.
4. In the repository, select **Add file → Upload files**.
5. Upload `index.html`, `style.css`, and `script.js` from this folder (not the ZIP itself).
6. Commit the files to the `main` branch.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch `main` and folder `/(root)`, then click **Save**.
10. Wait a few minutes and refresh the Pages section. GitHub will show the published website link, usually:
   `https://YOUR-USERNAME.github.io/read-nursery-school/`

Replace `YOUR-USERNAME` with your GitHub username. Use the exact link GitHub displays.

## Before presenting
- Replace placeholder school address, email, and phone number with verified details.
- Replace sample photos with approved school photos if available.
- In `script.js`, replace `ADD-SCHOOL-EMAIL-HERE` with the school's real email address if you want the form to open a prepared email.
- The enquiry form is not a database-backed form. It uses the visitor's email application after a real email address is configured.
- Check the website on both phone and computer.

## Technologies to explain
- HTML gives the website its structure and content.
- CSS controls the design, layout, responsive behavior, and animations.
- JavaScript adds the mobile navigation, scroll reveal effects, and form interaction.
- GitHub Pages publishes the static website online for free.
